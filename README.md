# ЗАО «Атлант» — Информационная система учёта расхода инструмента и оснастки

Этап 1: вход пользователя и администратора с БД (SQLite).

## Запуск
1. Установите .NET 8 SDK и Visual Studio 2022 (рабочая нагрузка «Разработка классических приложений .NET»).
2. Откройте `AtlantTools.sln` двойным кликом (Visual Studio 2022) — NuGet-пакет `Microsoft.Data.Sqlite` подтянется сам.
3. Нажмите F5.

При первом запуске рядом с exe создаётся файл `atlant.db` с двумя учётными записями:

| Роль          | Логин | Пароль   |
|---------------|-------|----------|
| Администратор | admin | admin123 |
| Пользователь  | user  | user123  |

## Что умеет
- Окно входа: проверка логина/пароля по БД, пароли хранятся в виде SHA-256 хэша, блокировка после 5 неудачных попыток, показ пароля.
- Администратор: таблица пользователей, добавление, включение/отключение, удаление (себя удалить/отключить нельзя).
- Пользователь: своё главное окно (пока заглушка под будущие модули).
- Регистрация: ссылка «Нет аккаунта? Зарегистрироваться» на окне входа. Проверяются ФИО, логин (латиница/цифры/_, от 3 символов, уникальный), пароль (от 6 символов) и его повтор. Роль новой учётки всегда «Пользователь», администратора создаёт только администратор.
- «Файл → Сменить пользователя» возвращает на окно входа.

## Вход
Окно входа с двумя вкладками: **«Администратор»** и **«Пользователь»**. Вкладка определяет, как вы входите:
учётная запись должна быть той же роли (admin на вкладке «Пользователь» и наоборот не пустит).
Регистрация (ссылка внизу) есть только на вкладке «Пользователь» и создаёт обычного пользователя;
дополнительных администраторов создаёт администратор в своей панели.

## Этап 2: складской учёт
Главное окно пользователя: меню *Ввод документов / Просмотр информации / Дополнительные функции / Помощь / ВЫХОД*.

**Ввод документов** (4 вида):
- *Приходный ордер → От поставщика / Со служб завода* — шапка (номер, дата) и позиции. В окне «Ввод нового» вводятся
  код материала (6 цифр), наименование, единица измерения (кодом), цена, количество; сумма считается сама.
  Если кода нет в справочнике, материал можно добавить прямо в этом окне.
- *Лимитная карта*, *Требование-накладная* и *Товарно-транспортная накладная* — расходные документы: выбирается
  получатель (цех или организация из справочника «Цеха и получатели»), позиции выбираются из остатков
  (код, единица и цена подставляются сами), списать больше остатка нельзя.
  Лимиты по лимитной карте и данные перевозчика в ТТН пока не хранятся и не контролируются.
- Остальные пункты меню показаны серыми — пока не реализованы.
- Каждая позиция документа — **отдельная запись в «Движении»**; остатки обновляются в той же транзакции.

**Просмотр информации:** Остатки, Движение (за период), справочники (только просмотр).
**Администратор:** меню «Справочники» (добавить / изменить / удалить) и те же «Остатки» / «Движение».

**Документы для проверки** (что вводить, в каком порядке и что должно получиться) лежат в отдельном документе.

### Таблицы БД (всё хранится кодами)
| Таблица | Поля |
|---|---|
| Stock (остатки) | Id, MaterialCode (до 15 цифр), Price, Quantity, UnitCode, Date |
| Materials (справочник материалов) | Id, Code (ровно 6 цифр), Name |
| Movements (движение) | Id, Date, DocNumber, DocTypeCode, IsExpense, MaterialCode, Quantity, UnitCode, Price, DepartmentCode |
| Units (коды ед. изм.) | Id, Code, Name (10 = кг, 101 = мкм, 102 = мм …) |
| DocTypes (коды документов) | Id, Code, Name (1/2 = приходный ордер, 3 = требование-накладная, 4 = лимитная карта, 5 = ТТН) |
| Departments (цеха и получатели) | Id, Code, Name |

`IsExpense`: **1 (true) = расходный, 0 (false) = приходный**.

## Структура
- `Database.cs` — работа с БД (таблица `Users`), хэширование, аутентификация
- `LoginForm.cs` — окно входа (вкладки «Администратор» / «Пользователь»)
- `RegisterForm.cs` — окно регистрации
- `AdminForm.cs` — окно администратора
- `UserForm.cs` — окно кладовщика (АРМ) с меню
- `DatabaseData.cs` — склад: таблицы, справочники, остатки, движение, проведение документов
- `DocumentForm.cs` — ввод документа (приходный ордер / требование-накладная)
- `LineForm.cs` — окно «Ввод нового» (позиция документа)
- `ViewForms.cs` — просмотр остатков и движения
- `ReferenceForm.cs` — справочники (коды)
- `UiHelper.cs` — общие мелочи для окон
- `Program.cs` — точка входа
